# PartyUp

Desktop cabinet. Electron 28, React 18, TypeScript 5, Vite 5.

## Stack
- Electron 28 + React 18 + TypeScript 5 + Vite 5
- sql.js for local data
- Zustand + Jotai
- Radix UI + Tailwind + Framer Motion
- i18next: EN, ES, FR, DE, JP, ZH, RU, PT, IT

## Services in this build
Library, Emulator, Metadata, Save manager, Playtime, Profile, Friends, Big Picture, Themes, Achievements, Downloads, Discord presence.

Emulators listed: RetroArch, Dolphin, PCSX2, DuckStation, PPSSPP, melonDS, Cemu, RPCS3, Citra, Vita3K.

## Not included
DLC unlockers, Steam emulators, and piracy torrent sources are not part of PartyUp.

## Run
```
npm install
npm run dev
```
